# dsh-pet官方动作参考：17段可上传MP4

这些片段用于给视频模型参考动作。成片的角色外观、比例和构图由你的图片1定义。

上游：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，固定版本[fb38ce62](https://github.com/PC2005-cloud/dsh-pet/commit/fb38ce620576f5ed3735a99536d2b1a4a9eb313f)，获取日期2026-11-17。

处理：校验上游Git blob SHA1 → 以libvpx-vp9真实解码alpha → 合成#EDEFF3浅灰背景 → H.264 MP4、640×360、24fps、无音轨。
保留原动作速度；没有用静态PNG伪造表演。原WebM缓存位于被忽略的work目录，删除后可从固定源重新获取。

拖拽只取原片3–7秒悬空中段；出错片原长约4.92秒，其余多数约10.04秒。这些是参考片时长，提示词目标统一10秒，按写好的编排表演。
多模态参考时只借其动作，不把参考视频人物、背景或字号图标复制到你的角色上。

索引由下面命令按照实际文件生成：

~~~powershell
python tools/prepare_motion_references.py
~~~

来源、上游Git校验值、原视频SHA256、输出SHA256、时长、尺寸及处理记录见[manifest.json](manifest.json)；
固定源清单见[sources.json](sources.json)。

角色原型署名、非商业及相同方式共享要求沿用[NOTICE.md](../../NOTICE.md)；
上游角色设计/二创原作者见该文件，转换为MP4不改变授权。用途为本项目个人桌宠二创的动作参考。
